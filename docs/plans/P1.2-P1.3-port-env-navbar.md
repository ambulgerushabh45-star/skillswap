## 1. Findings & Discovery

### Port 3000 & 3001 Audit
- Running `netstat -ano | findstr :3000` revealed that **port 3000 is occupied** by a listening `node.exe` process (PID 30292).
- Per task rules: "Do NOT kill any process. If port 3000 is in use: use 3001."
- Port 3001 was tested with `netstat -ano | findstr :3001` and is **completely free**.
- **Decision:** Fix development port to **3001** across all configurations and package scripts.

### Environment & Secret Files Audit
- `.gitignore`: Already contains rules for `.env`, `.env.*`, and `prisma/dev.db`. Verified that no secrets or databases are tracked by git.
- `.env`:
  - Contains `NEXTAUTH_URL="http://localhost:3000"` (needs alignment to `3001`).
  - Contains `PORT=3000` (stray variable not utilized by Next.js in dev mode; should be removed).
  - Contains `NEXT_PUBLIC_APP_URL="http://localhost:3000"` (needs alignment to `3001`).
  - Contains development placeholder `NEXTAUTH_SECRET`. Per rule, instructions for generating a secure secret (`openssl rand -base64 32`) will be added to `.env.example`.
- `.env.example`: Needs comprehensive documentation with every variable name, clear one-line comments, and placeholder values.

### Navbar Audit (`src/components/Navbar.tsx`)
- Currently renders `Find Matches` (`/dashboard`) and `Local Events` (`/events`) in desktop `<nav>`.
- Has no link to `/chat`.
- Lacks active route highlighting (`usePathname`).
- On screens `< md`, `<nav>` is hidden. A responsive implementation should show the text link on desktop and a compact icon link on mobile alongside user actions without breaking the flex layout.

## 2. Implementation Steps

### Task P1.2: Port & Env Alignment
1. **`package.json`**: Update `"scripts"`:
   - Change `"dev": "next dev"` to `"dev": "next dev -p 3001"` so Next.js binds explicitly to 3001 and fails loudly if busy instead of silently port-drifting.
2. **`.env`**:
   - Update `NEXTAUTH_URL="http://localhost:3001"`.
   - Update `NEXT_PUBLIC_APP_URL="http://localhost:3001"`.
   - Remove stray `PORT=3000`.
   - Keep existing `DATABASE_URL`, `NEXTAUTH_SECRET`, and Google OAuth variable names intact without printing secrets.
3. **`.env.example`**:
   - Document all application variables: `DATABASE_URL`, `NEXTAUTH_URL`, `NEXTAUTH_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `NEXT_PUBLIC_MAP_PROVIDER`, `NEXT_PUBLIC_APP_URL`.
   - Include openssl generation instructions for `NEXTAUTH_SECRET`.
4. **`docs/DECISIONS.md`**:
   - Log the choice of port 3001 and explicit `-p 3001` flag.

### Task P1.3: Navbar Messages Link
1. **`src/components/Navbar.tsx`**:
   - Import `usePathname` from `next/navigation`.
   - Import `MessageCircle` from `lucide-react`.
   - In desktop `<nav>`: when `status === "authenticated"`, render "Messages" link to `/chat` with active state styling when `pathname === "/chat"`.
   - Include comment: `{/* TODO (P4.1): Add real unread messages count badge here */}`.
   - For mobile layout: when `status === "authenticated" && session?.user`, render a compact `MessageCircle` icon link before the user profile avatar that highlights when active.
