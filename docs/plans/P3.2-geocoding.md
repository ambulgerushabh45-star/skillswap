# Plan: P3.2 — Address Search (Geocoding) via OpenStreetMap Nominatim

## 1. Goal
Implement a compliant, privacy-preserving, and cached address geocoding endpoint at `GET /api/geocode?q=...` and integrate it into the `CreateEventDialog` component, allowing event hosts to search for meetup addresses, select from search results, and automatically populate event coordinates while preserving manual coordinate entry as a fallback.

---

## 2. Nominatim Usage Policy & Compliance Rules
OpenStreetMap Nominatim is a free community service with strict usage requirements:
1. **Custom User-Agent Header**:
   - Value read from `process.env.NOMINATIM_USER_AGENT`, defaulting to: `"SkillSwap/0.1 (contact: set-in-env)"`.
   - Must identify the application and contact point.
   - Documented in `.env.example`.
2. **Server-Side Throttle (1 req/sec)**:
   - Global timestamp/queue gate ensuring no more than 1 request per second hits Nominatim across the whole server instance.
3. **No Search-as-You-Type**:
   - The frontend triggers geocoding strictly upon explicit user action (clicking "Search address" or pressing Enter in the search input).
4. **24-Hour Memory Cache**:
   - Normalized query -> cached results stored for 24 hours (`86_400_000 ms`).
   - Hard size cap (e.g. 500 entries) with LRU/oldest eviction to prevent unbounded memory growth.
5. **Attribution**:
   - Display `"© OpenStreetMap contributors"` clearly near the search results.
6. **Privacy Guard**:
   - Server sends ONLY the address query to Nominatim. Never forward user ID, email, session cookies, or client IP headers.
   - The browser never contacts Nominatim directly; all requests proxy through `/api/geocode`.

## 3. Route Design: `GET /api/geocode?q=...`

### Execution Order:
1. **Authentication Guard**: `requireSession()`. Returns 401 Unauthorized if unauthenticated.
2. **Rate Limiting**: `rateLimit("geocode:search:${auth.user.id}", { limit: 20, windowSeconds: 60 })`.
   - Returns standard 429 Too Many Requests if the user exceeds 20 searches per minute.
3. **Query Validation**:
   - Schema: `geocodeQuerySchema` in `src/lib/validators/geocode.ts`.
   - `q`: string, trimmed, min 3 characters, max 200 characters.
   - Returns standard 400 Bad Request with field error if invalid.
4. **Cache Lookup**:
   - Query normalized via `normalizeGeocodeQuery(q)` (trimmed, lowercased, multiple spaces collapsed).
   - If found and not expired in `GeocodeCache`, returns `{ results }` with `X-Cache: HIT`.
5. **Throttled Upstream Call**:
   - Wait if necessary until 1,000ms has elapsed since the last upstream request.
   - URL: `https://nominatim.openstreetmap.org/search?q=${encodeURIComponent(normalizedQ)}&format=jsonv2&limit=5&addressdetails=0`
   - Headers: `{ "User-Agent": userAgent, "Accept": "application/json" }`.
   - 5-second timeout via `AbortSignal.timeout(5000)`.
6. **Error Handling**:
   - On network error, timeout, HTTP 429, or HTTP 5xx: return 503 Service Unavailable with friendly message:
     `{ "error": "Address search is unavailable right now. You can enter coordinates manually." }`.
   - Never leak raw upstream errors or the User-Agent string. Never cache failures.
7. **Response Parsing & Cache Storage**:
   - Parse JSON array, validate each item:
     - `label`: `display_name` trimmed to max 150 chars.
     - `latitude`: `parseFloat(lat)`, must be valid number between -90 and 90.
     - `longitude`: `parseFloat(lon)`, must be valid number between -180 and 180.
   - Clamp to max 5 valid results. Empty results return 200 with `{ results: [] }`.
   - Cache results in memory cache for 24 hours.
   - Return `{ results }` with `Cache-Control: private, no-store` and `X-Cache: MISS`.

## 4. Pure Helpers Module: `src/lib/geocode.ts`
- `normalizeGeocodeQuery(query: string): string`
- `parseNominatimResponse(raw: unknown): GeocodeResult[]`
- `GeocodeCache`: Class supporting `get`, `set`, `size`, `cleanup`, and LRU/oldest eviction.
- `NominatimThrottler`: Class managing a 1-second delay gate between upstream executions with injectable clock and sleep function for deterministic unit testing.
- `fetchGeocodeNominatim(query, options)`: Throttled, cached fetch wrapper with injectable fetch for testing.

## 5. UI Enhancement: `src/components/CreateEventDialog.tsx`
- **Search Input**:
  - Address search field with placeholder: `"Search address or landmark (e.g. Cubbon Park, Bengaluru)"`.
  - "Search address" button (with `Search` icon). Disabled while searching or if input length < 3.
  - Pressing Enter triggers search without submitting the form.
- **States**:
  - `idle`: Input ready.
  - `searching`: Search button disabled with spinner / `"Searching..."` text.
  - `results`: Up to 5 selectable results. Clicking a result sets `lat` (6 decimals), `lng` (6 decimals), and pre-fills the location text field if empty.
  - `selected`: Shows `"Location set: <selected label>"` badge/confirmation.
  - `no results`: Notice `"No results found. Try adding the city, or enter coordinates manually below."`.
  - `error`: Friendly banner with API error message.
  - `attribution`: `"© OpenStreetMap contributors"` displayed under results.
- **Stale Response Protection**:
  - Incrementing request ID counter to discard responses from superseded queries.
- **Manual Fallback**:
  - Collapsible section `"Enter coordinates manually"` containing `Map Lat` and `Map Lng` inputs.
  - Existing form submission remains 100% backward-compatible.

## 6. Testing Plan
1. **Unit Tests (`src/lib/geocode.test.ts`)**:
   - Query normalization (spaces, casing, trimming).
   - Parsing valid, malformed, empty, and non-numeric lat/lon responses.
   - Label truncation and result limit (max 5).
   - Cache operations: set, get, TTL expiration with fake clock, eviction upon cap limit.
   - Throttle execution: verifies 1,000ms delay between consecutive upstream calls using fake timers.
   - Zero real network calls in Vitest.
2. **Integration Script (`scripts/geocode-check.mjs`)**:
   - Unauthenticated access returns 401.
   - Invalid `q` (missing, < 3 chars, > 200 chars) returns 400.
   - Valid search returns 200 with numeric coordinates (at most 2 real queries with >= 1s pause).
   - Repeat query returns 200 with `X-Cache: HIT` (cache verification).
   - Full-text leak check: `NOMINATIM_USER_AGENT` value never present in response body or headers.
   - Graceful offline handling: reports SKIPPED if network is unavailable.
   - Zero database rows created.
